# Parsel ölçümü — bakım duyarlılık ızgarası (bakim-c-izgara-r6)

Her satır bir (kıtlık aşınması `kitlikAsinmaPpmGun`, ceza tavanı `asinmaVerimKaybiTavaniPpm`) ayarıdır; bakımsız = yönetim kapalı, bakımlı = bakım yönetimi AÇIK; hücreler "bakımsız / bakımlı / oran" biçimindedir. **Bulgular ve yorum (elle yazılmış):** [bakim-asinma-c.md](bakim-asinma-c.md)
